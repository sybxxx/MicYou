# 本地版本：以官方稳定版为底座

本分支基于官方 v2.2.0（`1ae431875a215d21812ef54a64ddb16a5f741c25`）。旧版源码保留在 `master`（`7f29e3e`），候选版本使用 `2.2.0+local.1`，不覆盖正在使用的安装。版本的 `+local.1` 标明本地构建，保留 v2.2.0 的插件最低宿主版本兼容性。

## 必须保留的使用结果

- 手机经 Wi-Fi 传音，保留上游 Opus 编码和插件支持。
- 加密会话保留身份、配对及防降级规则；连接失败不能自动变成明文连接。
- 网络重连不释放正在录音的 AudioRecord；取消和明确停止仍须释放资源。
- 已连接意味着音频已进入主输出队列；控制连接存活但音频停止时可检测并恢复。
- 旧会话退出不能清除新会话；TCP 拥塞不能无限积累过期音频。
- 关闭窗口仍遵循隐藏或退出的选择；Windows 用户安装只采用 Inno Setup。

## 协议边界

上游 MessageWrapper 的 7、8 已用于插件消息和链路统计。本地加密握手改用 100–103，Ping 的音频健康确认使用字段 2、3。手机和电脑候选版本须成套构建、测试和升级；不承诺与旧本地版本混用。迁移保留现有身份与配对文件格式，实际资料不得由构建或测试改写。

## 后续更新

跟随官方稳定发布，不逐个反向搬运上游补丁。升级时比对本地独有的加密、恢复、窗口及安装行为；上游已有等价实现的旧补丁不重复移植。自动应用补丁不能代替协议和生命周期检查。

候选构建和安装是两个阶段。替换安装前，保留旧安装包及原有配置与配对资料；回退需恢复同一套旧手机与电脑版本，避免新旧协议混用。不得为升级关闭更新、清除配对或降低加密要求。

## 验收

测试与产物构建放在公开 fork 的 GitHub Actions `Local Candidate Build`：只构建 Windows 与 Android，不发布 Release，不修改远程 master。推送候选分支后自动运行；产物保留一天，本机只做轻量检查与下载。Android 使用仓库已配置的发布签名密钥，不上传本机密钥或个人配置。

2026 年 11 月 17 日，用户报告当前安装在 CPE 的 5 GHz 下异常，切换到 2.4 GHz 后可用。后续以可用的 2.4 GHz 链路作对照；这项改善来自网络切换，不能归因于尚未安装的候选版本。

自动检查覆盖协议、加密、会话交错、缓冲恢复和前端类型。实际使用还需手机 → Wi-Fi → 电脑 → 虚拟麦克风验收：持续语音识别、断网后恢复、重连有声音、延迟不持续增长，以及静音和停止仍正常。真实设备验收须在确认安装候选版本后进行。

关闭“同步静音状态”后，手机静音至少 15 秒应保持连接，电脑静音开关不变；解除手机静音后应恢复收音。手机主动暂停传音与电脑输出静音是两个状态，健康检测必须区分。
