# 本地版本：以官方稳定版为底座

本分支基于官方 v2.2.0（`1ae431875a215d21812ef54a64ddb16a5f741c25`）。旧版源码保留在 `master`（`7f29e3e`），候选版本使用 `2.2.0+local.2`，构建与替换安装分开确认。版本的 `+local.2` 标明本地构建，保留 v2.2.0 的插件最低宿主版本兼容性。

## 必须保留的使用结果

- 手机经 Wi-Fi 传音，保留上游 Opus 编码和插件支持。
- 加密会话保留身份、配对及防降级规则；连接失败不能自动变成明文连接。
- 网络重连不释放正在录音的 AudioRecord；取消和明确停止仍须释放资源。
- 已连接意味着音频已进入主输出队列；控制连接存活但音频停止时可检测并恢复。
- 旧会话退出不能清除新会话；TCP 拥塞不能无限积累过期音频。
- 关闭窗口仍遵循隐藏或退出的选择；Windows 用户安装只采用 Inno Setup。
- 隐藏或最小化主窗口只暂停可视化，不停止音频或挂起配对、连接通知和托盘操作。

## 协议边界

上游 MessageWrapper 的 7、8 已用于插件消息和链路统计。本地加密握手改用 100–103，Ping 的音频健康确认使用字段 2、3。手机和电脑候选版本须成套构建、测试和升级；不承诺与旧本地版本混用。迁移保留现有身份与配对文件格式，实际资料不得由构建或测试改写。

`2.2.0+local.2` 仅修复桌面可视化开销，未更改协议；电脑端可以继续配合已安装的 `2.2.0+local.1` 手机端使用，无需为此重装手机。前述成套升级要求针对旧 alpha 本地协议与 2.2 稳定底座的首次迁移。

## 后续更新

跟随官方稳定发布，不逐个反向搬运上游补丁。升级时比对本地独有的加密、恢复、窗口、后台低占用及安装行为；上游已有等价实现的旧补丁不重复移植。自动应用补丁不能代替协议和生命周期检查。

Android 保留数据更新还要求签名兼容。现有云端 APK 的签名与手机已装版本不同，不能直接覆盖：先核对原签名密钥的公共证书与已装应用一致，再通过现有 `ANDROID_KEYSTORE_PATH`、`ANDROID_KEYSTORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD` 环境配置，用本机 Android SDK 的 `apksigner` 完成轻量最终签名。保留原始云端 APK，将签名输出另存；经 `apksigner verify` 验证有效并确认签名证书匹配后，才用 `adb install -r` 保留数据安装。

后续云端 APK 若仍与已装签名不匹配，也要重复这一步本机最终签名；编译继续由云端完成。原密钥与个人配置不上传，不替换云端签名 Secrets。

替换安装前，保留旧安装包及原有配置与配对资料。旧 APK 备份不等于能够保留数据降级；回退前须核对 Android 版本降级限制，不能擅自卸载或清数据。允许回退时，手机与电脑也须恢复为兼容的一套版本，避免新旧协议混用。不得为升级关闭更新、清除配对或降低加密要求。

## 验收

测试与产物构建放在公开 fork 的 GitHub Actions `Local Candidate Build`：只构建 Windows 与 Android，不发布 Release，不修改远程 master。推送候选分支后自动运行；产物保留一天，本机只做轻量检查、下载与必要的最终签名，不重新编译。云端 Android APK 使用仓库已配置的发布签名；更新已有手机安装时，按前述流程完成本机最终签名。

2026 年 11 月 17 日，用户报告当前安装在 CPE 的 5 GHz 下异常，切换到 2.4 GHz 后可用。后续以可用的 2.4 GHz 链路作对照；当时候选版本尚未安装，这项改善来自网络切换。

自动检查覆盖协议、加密、会话交错、缓冲恢复和前端类型。实际使用还需手机 → Wi-Fi → 电脑 → 虚拟麦克风验收：持续语音识别、断网后恢复、重连有声音、延迟不持续增长，以及静音和停止仍正常。真实设备验收须在确认安装候选版本后进行。

后台低占用回归检查包括隐藏与最小化时停止音量环、监控波形和 CSS 循环动画，恢复窗口后继续刷新；前台音量事件间隔至少 75 毫秒，音量环每帧间隔至少 33 毫秒。后台仍须响应断连、安全状态、静音与配对请求。实机 CPU 降幅须在相同传音及窗口状态下对照安装前后测量，不能以浏览器测试代替。停用此修复可只恢复 `2.2.0+local.1` 桌面安装，不必降级手机或改动配对资料。

关闭“同步静音状态”后，手机静音至少 15 秒应保持连接，电脑静音开关不变；解除手机静音后应恢复收音。手机主动暂停传音与电脑输出静音是两个状态，健康检测必须区分。
